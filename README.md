# Site — Mentorat Elisama Knickerbocker

Site statique (une page) : challenge gratuit + mentorat 1:1, méthode DMAIC.

## Contenu

- `index.html` : la page complète (HTML, CSS et un petit script pour le formulaire en 3 étapes)
- `assets/` : les trois photos utilisées

## Mettre en ligne avec GitHub Pages

1. Sur GitHub, crée un nouveau dépôt (par exemple `mentorat-pharma`).
2. Clique sur « Add file » → « Upload files », puis glisse `index.html`, `README.md` et le dossier `assets`.
3. Clique sur « Commit changes ».
4. Va dans « Settings » → « Pages ». Sous « Build and deployment », choisis la source « Deploy from a branch », la branche `main` et le dossier `/ (root)`, puis « Save ».
5. Après une ou deux minutes, le site est en ligne à l'adresse indiquée sur cette page (du type `https://<ton-identifiant>.github.io/mentorat-pharma/`).

Si le dépôt est public, tout le monde peut voir son contenu (le code et les photos).

- **Formulaires** : ils n'envoient rien pour l'instant. Il faut les brancher sur un outil (Systeme.io, Tally, Formspree…). Le point de branchement est indiqué dans le script, en bas de `index.html` (« À BRANCHER »).
- **Dates du challenge** (17–19 janvier 2027) : à confirmer.
- **Mention TVA** : à valider avec l'expert-comptable.
- **CGV, rétractation, mentions légales, politique de confidentialité** : à rédiger (avec l'avocate) et à relier aux liens du pied de page.
- **Témoignages** : l'emplacement en pointillés est à remplacer par de vrais témoignages, avec l'accord écrit des personnes, ou à supprimer.
- **Employeur** : vérifier la politique interne sur les activités annexes avant publication.
